The proposed owner captures room/account/thread and an immutable local session, owns recognition callbacks/restart/stability timers and one HTTP request lease, and rechecks ownership immediately before queued transport dispatch and after callbacks/publication. A 700ms unchanged interim piece is applied once, final results deduplicate it, and natural recognition end restarts after 150ms while live. Each piece uses the current same-room side file unless a live card is active, plus the last ten successful pieces. Successful responses can switch card/file mode. The target file callback never routes through the fullscreen Viewer.

Stopping revokes recognition, drains already-owned work, then requests one ordinary human review message with the successful transcript and last file/card reference. HTTP timeout/network failure is uncertain because the server may have stored data before its final response; it stops recording and blocks automatic replay/review. Known global401 and membership403 have separate typed callbacks; generic403/provider errors do not revoke global identity. Closing an uncertain session clears local state, not server work or a claimed rollback.

Review sends use Promise room requests and existing Composer canonical matching: baseline message ID, own author, exact thread/text/files/reply. ACK alone does not show completion. A post-ACK canonical wait is bounded; lost ACK/unknown results retain an unconfirmed state without automatic retry. The wire does not correlate a resulting message ID to the request, so a concurrent identical own message remains an ambiguity just as in the existing Composer owner. No other Composer draft is cleared by a Fire review.

A pointer tap toggles dictation; a 3s hold arms Fire, with a finite Studio-token charge indicator after 400ms. Physical keyboard Space retains the existing 350ms hold/short-tap/fast-typing behavior; coarse-pointer keyboards pass Space through. Submit synchronously cancels dictation callbacks and pending charge so late speech cannot rewrite the emptied draft. First-use consent and session controls use immutable Snapshot bindings. No new CSS file, first-party inline style, palette, raw HTML, vendor family or real-provider acceptance is introduced.
