# Native runner Fire parity

Source checkpoint against upstream main `3b86acb`, based on merged `2d1b6ae` with the separate backend protocol prerequisite `5f1c8dd` (local equivalent `0101429`). Do not cherry-pick the prerequisite copy when integrating native commits.

The old fast-model generation, per-pause POSTs, card activity shimmer, first-use cost dialog, and Stop-to-review message are retired. Fire now switches the person's own room Claude through `{on}`, reflects authenticated runner `fireState` reports, records one utterance, and on release sends audio to the real Whisper endpoint. Browser recognition supplies preview and the existing fallback only. The resulting transcript is an ordinary captured-thread message through the existing Composer request adapter, so current viewing metadata belongs to the same canonical adapter as typed messages.

Empty-composer desktop Space held 350ms enters recording; a tap inserts a space. Nonempty-composer holds retain ordinary dictation. Outside editable/button controls, desktop Space held 300ms records and release sends. Mic tap retains dictation, 3s enters Fire, and subsequent taps toggle recording. Escape and Leave request the previous model; `off` is the runner confirmation. A missing report remains explicitly unconfirmed rather than claiming restoration.

Recorder ownership fences permission promises, chunks, browser recognition, recorder stop/error, STT results and message completion by immutable account/room/thread/session/utterance. Permission and HTTP work have independent bounded leases; an ignored late permission result is disposed. One-second recorder chunks enforce the shared 4MB cap before indefinite browser buffering. Release before permission, blur/hidden/Send intent, membership loss, navigation and disposal stop owned media and prohibit late speech writes. Synchronous room departure hooks request model restoration before releasing the scope; private transcripts are cleared on departure. On/off has no server request revision, so model restoration is not claimed from HTTP success or silence; native code cannot promise ordering of arbitrary delayed runner reports.

The personal channel remains the singleton socket owner. Fire reports are delivered only through its current authenticated socket, account and exact active Book connection, with guards repeated between reentrant listeners. No per-room socket or global private cache was added.

Normal message ACK and canonical delivery stay separate. A bounded own-author/thread/text/files/baseline match confirms a transcript; timeout/disconnect retains it without automatic resend. Definite prequeue refusal permits only an explicit retry, guarded by the captured utterance intent. A user may discard an uncertain utterance after reviewing the conversation. As with existing Composer messages, the wire result has no canonical message ID; identical concurrent own-author messages remain an acknowledged ambiguity of payload correlation.

Fourteen replacement pure cases and a replacement actual native Composer DOM case are authored, plus a personal-channel reentrant/identity case. Existing ordinary dictation/late-after-Send/dialog-focus tests remain. At this checkpoint all formatting, pure tests, full UI/types, DOM, real runner/Whisper, browser microphone and real hardware gates are UNRUN. No provider fixture, old fast-model browser audit, deployment, or real speech acceptance is claimed.
