# Runner Fire and Workers AI speech boundary

Main `3b86acb` replaces server-side fast-model Fire editing with the person's own Claude/runner. `POST /api/books/:id/fire` now accepts only `{on:boolean}` and returns `{ok:true}` after an owned membership update. The typed route updates `members.fire_at`, emits the typed personal `fire` notice and retains the existing analytics. There is no server-model card/file generation, transcript/review result, or successful runner-switch claim in this response. Only the separate validated `fireState` notice reports switching/ready/off/failed. Unknown state literals are refused; optional model/note are bounded to the producer's limits.

`POST /api/books/:id/stt?lang=&prompt=` consumes raw audio, with the existing per-person upload limiter and membership authorization. Bytes are limited to 4,000,000 while streaming even when Content-Length is absent. Empty, malformed-length and oversized bodies are rejected before AI. The Worker calls the installed typed Whisper binding without `as never`/response assertions. Runtime validation accepts the provider's optional text (missing text preserves the upstream empty-string behavior), rejects malformed text, trims the result, and bounds text at 65,536 characters. Language/prompt defaults and 5/600-character normalization preserve upstream behavior. Membership is rechecked before paid transcription and before delivering its result; a removed member receives 403 rather than late speech data. Provider/shape failures retain 502 for authorized members.

Both routes are chained into inferred Hono `AppType`, and their shared schemas are browser-safe. The Fire JSON body has a 1KiB streamed bound. Audio MIME is deliberately unrestricted like upstream; this does not assert that every recording codec is supported by Whisper. The native adapter sends raw bytes through the inferred endpoint's fetch initialization, keeping the inferred query and response contract.

The old server-model authority fixture is retired from the same isolated test path; live-card membership and deferred R2 publication/cleanup regressions remain. New actual-handler fixtures cover switch authorization/SQL scope, retired payload refusal, raw-audio bounds/rate, runtime output refusal and late membership revocation. Actual transcription normalization and stream cancellation use a fake Workers AI callback and synthetic bytes. These checks do not prove microphone capture, real Whisper service/codec delivery, real runner model switching, provider billing or deployment. Current native ports and browser/Worker integration remain separate gates.
