# Semantic Markdown parser experiment

This source experiment starts from deployed main `3a73dff`. It does not establish a performance improvement or accept any migration budget. Vanilla remains the default; styles, fonts, canonical rendering readiness and original performance thresholds are unchanged.

Marked 12.0.2 lexes once. A bounded token traversal selects the full parser if any raw HTML token exists, including nested inline/list/table content. HTML-free Markdown uses a typed HTML-namespace tree builder; one shared semantic token emitter drives both builders. Raw HTML uses the whole-input pinned parse5 8.1.1 adapter, retaining its streaming flush, repair and namespace behavior. The same projector handles sanitization, URLs, mentions, source metadata and resource policy. Entities stays eager because URL validation also depends on exact decoding.

`prepareRichSource` is synchronous lexical preparation; `parsePreparedRichSource`, `parseRichSource`, projection and RichSession rendering remain synchronous. Pure callers explicitly supply the full parser factory for HTML. Missing preparation is a programming error outside the literal-source fallback catch. Existing tests inject that factory without changing their semantic assertions.

RichContent and DocumentPreview own cold HTML acquisition before synchronous parsing. Ordinary Markdown remains immediately ready. Each gate captures source, mode, policy and account/room/document identity; replacement/disposal aborts its ownership, clears cancelled source/token holders and refuses late results. Current authority is checked again around asynchronous completion. Cold acquisition has a 15-second deadline and visible retryable failure, rather than rendering valid HTML as permanent literal fallback. Retry and failure publication are fenced against synchronous subscriber/abort reentrancy. Mermaid passes its effect-owned abort signal through its existing asynchronous render boundary and uses bounded HTML acquisition before synchronous SVG sanitization.

The new pure suite compares semantic trees, metadata and sanitized projections against the actual full parser for GFM blocks, lists, references, entities, code, document spans and limit cases. It also checks raw HTML selection/repair/namespaces and acquisition lifecycle races. Existing rich-text, file-index and document semantic assertions remain registered. New actual-component source fixtures cover synchronous ordinary content, cold dynamic acquisition, failure/Retry, source/account/room replacement and disposal. These component fixtures require remote execution; local author verification runs no Svelte compiler, browser, build or performance job.

Initial local author run encountered an unchanged missing `entities-legacy` dependency in the compatibility suite; that suite remains in its mandatory gate and must pass in the complete dependency environment. The successful focused rerun excludes only that dependency-blocked suite. Exact final test counts and commit are reported separately.

Before adoption, run all source/build/component gates and unchanged real browser coverage, including raw HTML and diagrams. Inspect the actual emitted import graph and requested resources: a fallback imported by any eager facade would erase the intended transfer benefit, and real raw HTML legitimately loads the parser before canonical readiness. Rendered raw module contributions are not gzip savings. Measure the original complete performance cohort without weakening readiness or budgets; font transfer and post-GC heap remain independent requirements, and a loaded parser module remains in the browser module cache.
